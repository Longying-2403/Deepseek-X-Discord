# DeepSeek 群友（Discord Bot）

**中文** | [English](https://github.com/Longying-2403/Deepseek-X-Discord/tree/english)

[![tests](https://github.com/Longying-2403/Deepseek-X-Discord/actions/workflows/tests.yml/badge.svg?branch=main)](https://github.com/Longying-2403/Deepseek-X-Discord/actions/workflows/tests.yml)

一个用 DeepSeek V4.1 Flash（`deepseek-flash`）驱动、像普通群友一样待在 Discord 服务器里的 bot：

- **被叫到就回**：有人 @ 它、回复它的消息、或叫它的别名，立刻回应。
- **主动接话**（按频道开启）：像人一样隔几分钟看一眼频道，有人在聊、又真有话想说才开口（默认倾向沉默）；开了口、或者被叫过之后会跟着这场聊天接话，没人说话了、或者插不上话了就回到隔几分钟看一眼。
- **像真人**：口语化，长短看场合（随口接话一两句，接剧情时多写几句）；先显示“正在输入”，按字数等几秒再发；可以把一段话拆成两三条。不需要说什么的（道谢、晚安、哈哈哈）就只加个表情。别人聊得正起劲时也会委婉地插一句，被拒绝就道个歉，这个话题里不再插话。
- **会 @ 人**：它话里写的 @某人、#频道 会变成真的 @ 和频道链接；有人叫它的时候，被 @ 的人才会真的收到提醒。
- **跟着删改**：群友删掉的消息，它的聊天记录里也跟着删掉；编辑过的消息，它会以改过之后的内容为准。
- **会用服务器的表情和贴图**：知道这个服务器有哪些自定义表情和贴图，回复里、加表情反应、单独发一张贴图都行。
- **能陪着演**：群友拉它角色扮演时，照设定演、跟着剧情走，动作写在斜体括号里；戏散了自动回到平时的样子。
- **记得每个人**：每个群友一张人设卡（他自己说的称呼、设定比如自称猫娘、喜好和雷点），聊天时自然地用上（默认每个服务器一张，也可以设成所有服务器共用一张，见“十一”）；还有一份这个服务器的长期记忆（约定、大事、长期的梗和剧情）。说“记住……”当场记下，平时它会趁聊天安静下来时自己整理。人设卡的原文只有本人能看、能改（`/ds-rp`），管理员也看不到；别人问起时它只会用自己的话大概说说，不会照念原文。
- **dsowner 能在聊天里改人设**：`OWNER_ID` 本人叫它说“以后说话毒舌一点”，它会把人设改好并存进设置，说“改回去”还能撤销；别人这么说，它会让对方找 dsowner。
- **话量可控**：多久看一眼、聊起来以后跟不跟着，都能在 Discord 里调（安静 / 普通 / 话痨三个档位一键套用）。
- **会自己冒泡**（按频道开启）：频道安静了几个小时，它会自己来说点什么：从大家聊过的东西里看出感兴趣的话题，去搜最近的新鲜事（多半是 X 上的）分享一条，或者打个招呼。只在白天，一天最多几次，上次冒的没人理就先不冒。
- **省钱**：对话历史只追加（只有消息被删、最近的消息被编辑时才改那一处），尽量吃满 DeepSeek 的前缀缓存；没额度时连判断都不做；每日预算超了自动降级。
- **能看图**：上传的图片、GIF 选单发的 GIF、贴的图片链接、链接预览的图、Discord 贴图都会一起发给模型（动图只看第一帧，可关）。
- **能读文件**：文本和代码、PDF（扫描件会看前几页的图）、Word、Excel、PPT。叫它时附上的文件直接读；“帮我看看上面那个文件”这种，它会自己去打开。
- **能打开链接**：平时看 Discord 生成的链接预览；被叫到时真的打开：X（推特）的推文走 FxTwitter（不用账号），别的网页交给 DeepSeek 读（读不了再交给 Tavily）。要登录才能看的网站只看预览。
- **会发表情包和图**：有表情包库（通用的放在 NAS 上，各服务器也能自己上传），也会上网找图——找到的图它先看一遍，合适才发。
- **能上网搜**：被叫到时，问到新闻、价格、比分、天气这类它不知道的最新信息，会先用 DeepSeek 的搜索查一下再回答（不到 1 秒）。每个服务器每天有次数上限。
- **跨频道记忆**（管理员开启）：在 A 频道跟它聊过的事，换到 B 频道它也接得上；也能翻开了共享的别的频道的记录。私密频道默认不外传。
- **会点歌**：进语音频道后叫它“放首晴天”，或者用 `/ds-music 播放`，它会进你所在的语音频道放 B站视频的声音；同一个语音频道里的人都能切歌、暂停、停止。只能放 B站的，不放直播。
- **能私信**：和它同在一个服务器的人可以直接私信它。私信里它用那个服务器的人设、长期记忆和你的人设卡，聊的事也会记回去，你在那个服务器的频道里叫它时也可能被提起（说“保密”的不会）；连着发几条，它等你说完再一起回；每人每天有花费上限（见“十四、私信”）。
- **私信记忆**：私信里聊到的、你们之间的事（最近在忙什么、约好的事、私信里玩的剧情），能写进人设卡的先写进人设卡，剩下的记进你自己的私信记忆，跟着你走、不分服务器。每条标着敏感不敏感：敏感的只在私信里用，不敏感的你在服务器里叫它时也会用上。用 `/ds-dm 记忆` 查看、删除、改成敏感（见“十四”）。
- **跨服务器**（管理员开启）：开了的服务器之间，同一个人最近跟它聊的会跟着他走，在 A 服务器聊的到 B 服务器也接得上（见“七”）。
- **服务器组**（Beta，bot 主人开启）：同一群人的几个服务器可以连成一组，当成一个服务器来记：共用人设卡和长期记忆，开了记忆共享的频道也能翻组里别的服务器的记录（见“七”）。
- **连通频道**（Beta，bot 主人开启）：把几个服务器的频道连通，共用一份聊天记录：在哪个频道叫它，它都知道别的频道刚才在聊什么；它在哪个频道就只在那里说话（见“七”）。
- **替你操作电脑**（可选）：你私信它“帮我开一下 Steam”，它就能替你开关电脑上登记过的程序、打开网址；只认你本人，电脑上要运行一个桌面小程序（见“十五”）。
- **区域可控**：可以按频道、类别或整个服务器限制它在哪里回应。

A Discord bot powered by DeepSeek V4.1 Flash (`deepseek-flash`) that hangs out in your server like any other member:

- **Answers when called**: when someone @mentions it, replies to one of its messages, or uses one of its aliases, it responds right away.
- **Joins in on its own** (per channel): like a person, it glances at the channel every few minutes and only speaks when people are chatting and it really has something to say (by default it leans toward staying quiet); once it has spoken or been called it follows the conversation, and steps back to glancing when the chat dies down or it has nothing to add.
- **Feels human**: casual, with the length fitting the moment (a sentence or two for a quick comeback, a few more when it's playing along with a story). It shows "typing…" first and waits a few seconds based on the length before sending; it can split a thought into two or three messages. When nothing needs saying (thanks, good night, lol), it just reacts with an emoji. When people are deep in a conversation it may tactfully chime in, and if it's told to stay out of it, it apologizes and keeps out of that topic.
- **Mentions people**: an @name or #channel in what it writes becomes a real mention or channel link; people only actually get notified when someone called it.
- **Keeps up with deletes and edits**: when someone deletes a message, it's deleted from its chat history too; for an edited message, it goes by the edited version.
- **Uses the server's emoji and stickers**: it knows which custom emoji and stickers this server has, and can use them in replies, as reactions, or send a sticker on its own.
- **Plays along**: when people pull it into a roleplay, it plays the part they set up and follows the story, with actions in italic parentheses; once the scene is over, it goes back to its usual self.
- **Remembers everyone**: each member gets a profile card (what they've said about themselves: what to call them, a character they've given themselves such as being a catgirl, likes and pet peeves), and it uses it naturally in chat (one per server by default, or one shared across all servers, see section 十一); there's also a long-term memory for the server (agreements, big events, long-running jokes and storylines). Say "remember …" and it saves it on the spot; otherwise it reviews the chat on its own once things go quiet. Only the card's owner can see and edit its original text (`/ds-rp`), not even admins; if someone else asks, it may sum it up roughly in its own words, but never reads the card out word for word.
- **dsowner can change its persona in chat**: when `OWNER_ID` calls it and says something like "be snarkier from now on", it rewrites its persona and saves it to the settings, and "change it back" undoes that; if anyone else asks, it tells them to ask dsowner.
- **You control how much it talks**: how often it glances and whether it follows a conversation can be adjusted from inside Discord (three presets: quiet, normal, chatty).
- **Bubbles up on its own** (per channel): when a channel has been quiet for a few hours it says something by itself: it works out from the chat what people are into, looks for something recent about it (mostly on X) and shares one item, or just says hello. Daytime only, a few times a day at most, and not again until someone has spoken.
- **Saves money**: the conversation history is append-only (only the spot where a message was deleted, or a recent one edited, gets changed), to get the most out of DeepSeek's prefix cache; with no quota left it doesn't even run a check; over the daily budget it scales back automatically.
- **Sees images**: uploaded images, GIFs from the GIF picker, pasted image links, link-preview images and Discord stickers are sent to the model too (only the first frame of animated images; can be turned off).
- **Reads files**: text and code, PDF (for scans it looks at images of the first few pages), Word, Excel, PowerPoint. Files attached to the message that calls it are read directly; for requests like "can you look at that file above", it opens the file itself.
- **Opens links**: normally it sees the link previews Discord generates; when it's called it really opens them: posts on X (Twitter) through FxTwitter (no account needed), other web pages through DeepSeek (Tavily as the backup). Sites you have to log in to see only get the preview.
- **Sends memes and pictures**: it has a meme library (a shared one on your NAS, and each server can upload its own), and it can also look for pictures online. It looks at what it finds first and only sends one if it fits.
- **Searches the web**: when it's called with a question about news, prices, scores, weather or anything else recent that it doesn't know, it looks it up with DeepSeek's search first (in under a second), then answers. Each server has a daily search cap.
- **Cross-channel memory** (turned on by admins): what you talked about with it in channel A carries over when you talk to it in channel B, and it can look through the history of other channels that share. Private channels don't share by default.
- **Plays music**: join a voice channel and ask it to "play some Jay Chou", or use `/ds-music 播放`, and it joins your voice channel and plays the audio of a Bilibili video; anyone in the same voice channel can skip, pause or stop. Bilibili only, no live streams.
- **Direct messages**: anyone who shares a server with it can DM it. In DMs it uses that server's persona, long-term memory and your profile card, and what you talk about can be remembered there too. When you call it in that server's channels, it may bring up what you just said in DMs (not the parts you asked to keep secret). If you send several messages in a row, it waits until you're done and answers them together. Each person has a daily spending cap.
- **DM memory**: things from your DMs that are between you and the bot (what you've been busy with, plans you made, a story you're playing in DMs) go on your profile card when they fit there, and the rest is saved to your own DM memory, which follows you across servers. Every entry is marked sensitive or not: sensitive ones are only used in DMs, and the rest may also come up when you call it in a server. View, delete or re-mark entries with `/ds-dm 记忆` (see section 十四).
- **Cross-server** (turned on by admins): between servers that turned it on, what a person just talked about with it follows them, so what they said in server A carries over to server B (see section 七).
- **Server groups** (Beta, turned on by the bot owner): several servers used by the same people can be linked into a group and remembered as one server: they share profile cards and long-term memory, and channels with memory sharing on can also look through the history of the group's other servers (see section 七).
- **Linked channels** (Beta, turned on by the bot owner): text channels in several servers can be linked so they share one chat record: wherever it's called, it knows what was just said in the other channels, and it only speaks in the channel it's in (see section 七).
- **Operates your computer** (optional): DM it "open Steam for me" and it opens or closes programs you've listed on your PC, or opens a web page. It only listens to you (`OWNER_ID`), and your PC needs to run a small desktop agent (see section 十五).
- **You control where it responds**: limit it by channel, by category, or for the whole server.

It replies in the language of the message it's answering, so it also works in mixed-language servers.

## 一、准备工作

### 1. 创建 Discord bot

1. 打开 [Discord 开发者后台](https://discord.com/developers/applications) → New Application。
2. 左侧 **Bot** 页：
   - 点 Reset Token，复制 token（填到 `.env` 的 `DISCORD_TOKEN`）。
   - 往下找到 **Privileged Gateway Intents**，打开 **Message Content Intent**（必须，否则看不到消息内容）。
3. 邀请进服务器：bot 第一次启动时会在日志里打印邀请链接（已带好权限）。也可以在后台 **OAuth2 → URL Generator** 里勾 `bot` 和 `applications.commands`，权限勾：查看频道、发送消息、在帖子中发送消息、读取消息历史、添加反应、嵌入链接、附加文件（发表情包和图要用；1.4.0 之前邀请的 bot 一般也有，因为 @everyone 默认就有这个权限）、连接、说话（点歌要用；之前邀请的 bot 一般也有，@everyone 默认就有）。

> 小规模用不需要审核。bot 进到 100 个服务器以上要先完成 Discord 的应用验证；能看到它的用户超过 1 万人时，Message Content 这个特权 intent 也要提交审核，到时 Discord 会通知你。

### 2. 准备 DeepSeek API key

在 [platform.deepseek.com](https://platform.deepseek.com) 创建 API key，并充一点余额（按量从余额里扣，不会产生欠费）。

### 3. 填 `.env`

```bash
cp .env.example .env
```

| 变量 | 说明 |
|---|---|
| `DISCORD_TOKEN` | 上面复制的 bot token |
| `DEEPSEEK_API_KEY` | DeepSeek 的 key |
| `OWNER_ID` | 你自己的 Discord 用户 ID（开发者模式下右键头像 → 复制用户 ID） |
| `CONTROL_GUILD_ID` | 想在 Discord 里改主人参数（预算、联网搜索、服务器组、连通频道等）就要填：放 `/dsowner` 的服务器 ID（右键服务器图标 → 复制服务器 ID）。平时聊天的服务器就行（朋友的也可以），命令和 `/dsadmin` 一样只有有“管理服务器”权限的人看得到，也只有 `OWNER_ID` 本人能用。2.7.0 起可以填几个，用逗号隔开（比如 `111…,222…`）：每个里面都有 `/dsowner`，在哪个里面用都一样，管的都是所有服务器。只填 `OWNER_ID` 不会有 `/dsowner` |
| `DISCORD_PROXY` | 可选。连 Discord 需要代理时填，如 `http://127.0.0.1:7890` |
| `TAVILY_API_KEY` | 可选。上网找图要靠 [Tavily](https://tavily.com)（每月免费 1000 次额度）；DeepSeek 没搜到、打不开的网页（比如 PDF），也会交给它再试一次。不填的话，联网搜索、读链接、按歌名找歌都照样能用，只是不能上网找图（表情包库照常能用） |

## 二、部署

### 方式 A：Docker Compose（推荐）

```bash
docker compose up -d --build
docker compose logs -f          # 看日志，确认“已登录”
```

数据库在 `./data/`。改了 `config.toml` 或 `.env` 之后，用 `docker compose up -d --force-recreate` 重建容器（`.env` 只在建容器时读，`restart` 不会重新读）。

用群晖 Container Manager 的话：改了 `.env` 或 `config.toml`，到“项目”里选中它 → 操作 → 停止，再 操作 → 构建（会删掉旧容器、用新的设置重建；数据在 `./data/` 里不受影响）。只在“容器”页面点重新启动不会读新的 `.env`，也不会换上新代码。

**更新到新版本**：代码是构建时复制进镜像的，所以要把新代码放进项目原来的文件夹，再重新构建：

1. 在 File Station 里先把项目文件夹里的 `dsbot` 文件夹整个删掉，再把压缩包里的 `dsbot` 复制进来；`Dockerfile` 和 `requirements.txt` 也用压缩包里的覆盖（2.2.0 起镜像里要多装 ffmpeg、yt-dlp 和语音库，这两个文件没换的话点歌用不了）。压缩包最外面有一层 `ds-discord-bot` 文件夹，要的是它**里面**的这几样；新代码要放进项目原来的文件夹，构建只认那里。先删再复制，免得复制时遇到同名文件选了“跳过”，旧文件还留在里面。`.env` 和 `data/` 不用动；`config.toml` 没改过的话一起覆盖，改过的话留着自己的也行（新参数都有默认值）。`docker-compose.yml` 没改过的话也一起覆盖（2.2.0 把关机时的等待时间 `stop_grace_period` 加到了 45 秒，让它有时间离开语音频道）；改过的话，自己把那一行改成 `45s` 就行。从 2.2.0 到 2.7.0 之间的版本更新到 2.7.1 只有 `dsbot` 文件夹变了（想用桌面操作的话，见“十五”）。2.8.1 的 `Dockerfile` 多了一步“构建时先把代码编译好”（启动、读文件都快一些）：没换成新的也照样能跑，只是慢一点。`config.toml` 里新加的参数不加也行，都有默认值；`[deepseek]` 下面的 `search_base_url`、`search_timeout_seconds`、`search_max_uses` 从 2.5.0 起用不到了，留着也没关系。
2. 重新构建。最稳的是 SSH 进 NAS，在项目文件夹里跑 `sudo docker compose up -d --build`（没有 `compose` 命令就用 `sudo docker-compose up -d --build`），这样一定会用新代码重建。Container Manager 的“构建”有时会沿用已有的旧镜像。
3. 确认新版生效了：日志里会有一行 `dsbot 2.11.0 启动中`（点歌能用的话，还会有一行 `点歌：开`），接着是 `已注册 4 个全局斜杠命令：…`，列出 `/dsadmin`、`/ds-rp`、`/ds-music`、`/ds-dm`（2.9.0 起管理员的命令从 `/ds` 改名成 `/dsadmin`，写法也变了，见“四、命令”）；或者跑 `sudo docker exec dsbot python -m dsbot --version`。
4. 如果日志里提醒 `config.toml 里有不认识的配置项`，多半是 `config.toml` 换成了新的、代码却还是旧的：回到第 1、2 步。（2.0.0 起这种情况只提醒、不会起不来；更早的版本会直接报错退出。）

### 方式 B：直接用 Python（3.11 及以上）

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m dsbot --check         # 离线自检：配置、斜杠命令定义（不连 Discord、不花钱）
python -m dsbot --test-search "台北 今天 天气"   # 可选：真的搜一次，确认联网搜索能用（花一点点钱）
python -m dsbot --test-link https://x.com/…/status/…   # 可选：真的打开一个链接（网页花一点点钱）
python -m dsbot --test-image "水豚"              # 可选：真的找一次图（用掉 1 次 Tavily 额度），候选图存到 data/找图测试/
python -m dsbot
```

点歌还要装 ffmpeg（比如 `sudo apt install ffmpeg`）；没装的话别的功能照常，只是点歌用不了，`--check` 会提醒。

## 三、上手

在服务器里（需要“管理服务器”权限）：

1. 先圈定它能待的地方（可选）：`/dsadmin 区域 禁止 范围:全服务器`，再到要用的频道执行 `/dsadmin 区域 允许`，或者选 `范围:本类别` 放开整个区
2. 在想让它主动聊天的频道里：`/dsadmin 设置 参数:主动发言 值:开`
3. 选个话量：`/dsadmin 档位`（安静 / 普通 / 话痨）
4. 给它定人设：`/dsadmin 人设`（弹出编辑框）；`OWNER_ID` 本人也可以直接在聊天里 @ 它让它改（见下面“十二”）
5. 想让它记得别的频道聊过的事：`/dsadmin 设置 参数:记忆共享 值:开 范围:全服务器`（见下面“七、跨频道记忆”）
6. 给它几张表情包：`/dsadmin 表情包 上传`（见下面“十、发表情包和图”）
7. 告诉群友：用 `/ds-rp` 可以看、改自己的人设卡（原文只有自己看得到；别人问起时它可能用自己的话大概说说），叫它“记住……”也行（见下面“十一、人设卡和长期记忆”）；想听歌就先进语音频道，再叫它“放首晴天”或者用 `/ds-music 播放`（见下面“十三、点歌”）
8. 想让它在某个频道安静久了自己冒个泡：在那个频道里 `/dsadmin 设置 参数:冒泡 值:开`（见下面“八、联网搜索”后面的“冒泡”）
9. 随时看状态：`/dsadmin 状态`（主动发言的节奏、现在的时间和时区、上次的判断和理由、今天花了多少、缓存命中率、记忆共享、搜索、读链接和找图的次数）；`/dsadmin 区域 查看` 看它在哪些地方会回应

不设置区域时，它在所有看得到的频道里都会回应点名；没开主动发言的频道里，它只在被叫到时说话。

> 建议在频道说明里告诉大家：这个频道的消息会发给 DeepSeek（服务托管在中国）处理。

## 四、命令

### `/dsadmin`（服务器管理员）

| 命令 | 作用 |
|---|---|
| `/dsadmin 区域 允许`、`禁止`、`跟随上级` | 让它在这里回应 / 不回应 / 删掉这一层的设置（跟着上一级走）。不允许的地方它完全不看消息：不回 @、不主动说话，也不发给 DeepSeek |
| `/dsadmin 区域 查看` | 列出这个服务器里允许和禁止的类别、频道，以及主动发言开着的地方 |
| `/dsadmin 设置` | 调整单项参数：主动发言、记忆共享、发图、别名、话量等（见“五、参数说明”）。选好参数，「值」一栏会弹出能填的（开 / 关 / 默认）；值填“默认”恢复成上一级的设置 |
| `/dsadmin 档位` | 一键套用主动发言的节奏：安静（每 10～15 分钟看一眼，说完不跟着聊）/ 普通（每 5～8 分钟，聊起来就跟着）/ 话痨（每 3～5 分钟，聊起来就跟着） |
| `/dsadmin 人设` | 修改人设（弹出编辑框）。`OWNER_ID` 本人也能在聊天里让它改，见“十二” |
| `/dsadmin 表情包 查看`、`上传`、`删除` | 这个服务器的表情包库：上传（附上图片、写个名字）；删除时「名字」一栏会列出这个服务器的表情包 |
| `/dsadmin 长期记忆 查看`、`添加`、`删除`、`清空` | 这个服务器的长期记忆：查看（选了编号就只看那一条的全文）、添加、删除（选编号，列表里有内容）、清空（会再确认一次） |
| `/dsadmin 兴趣 查看`、`添加`、`删除` | 这个频道的人感兴趣的话题（它冒泡时拿去搜最近的新鲜事）：它自己从聊天里看出来、搜过的会记在这里；可以自己加；删掉它看出来的，会记成“不让搜” |
| `/dsadmin 状态` | 查看本频道的设置、主动发言的节奏（多久看一眼、现在是不是正跟着聊）、现在的时间和时区、上次判断、今天花费、记忆共享、今天的搜索、读链接和找图次数、点歌的状态 |
| `/dsadmin 清空记忆` | 清空本频道的对话记录和摘要 |

“区域”的允许、禁止、跟随上级，还有“设置”“档位”“人设”，都有一个“范围”选项：**本频道**（默认，人设除外）、**本类别**（Discord 里的“XX区”）、**全服务器**。

> **2.9.0 起改了名字和写法**：管理员的命令以前叫 `/ds`，用“操作”一栏选做法；现在叫 `/dsadmin`，做法是子命令（必填的栏 Discord 会拦着不让漏，在 iPad、手机上也不会漏填）。`/ds-rp`、`/ds-dm`、`/ds-music`、`/dsowner` 没变。旧名字更新后就没有了，对照着换：
>
> | 以前（`/ds` 后面接） | 现在（`/dsadmin` 后面接） |
> |---|---|
> | `区域 操作:允许`（禁止、跟随上级一样） | `区域 允许`（`区域 禁止`、`区域 跟随上级`） |
> | `区域列表` | `区域 查看` |
> | `主动 开关:开` | `设置 参数:主动发言 值:开` |
> | `记忆共享 操作:开`（关、跟随上级） | `设置 参数:记忆共享 值:开`（值填“关”；填“默认”就是跟随上级） |
> | `表情包 操作:上传`（删除、列表） | `表情包 上传`（`表情包 删除`、`表情包 查看`） |
> | `长期记忆 操作:查看`（添加、删除、清空） | `长期记忆 查看`（`长期记忆 添加`、`长期记忆 删除`、`长期记忆 清空`） |
> | `档位`、`设置`、`人设`、`状态`、`清空记忆` | 后面的写法没变 |
>
> 在“服务器设置 → 整合”里单独给 `/ds` 调过权限的，要在 `/dsadmin` 上重新调一次（新命令默认还是只有“管理服务器”权限的人看得到）。Discord 的命令列表有缓存，更新后没看到 `/dsadmin` 就刷新一下（见“十七”）。

设置的优先级：**本频道 > 帖子所在的频道 > 所在类别 > 本服务器 > 主人设的全局值 > config.toml**。比如全服务器禁止、“闲聊区”类别允许、其中某个频道又单独禁止，结果就是只有闲聊区里除那个频道以外的地方会回应。

> 想彻底隔开某些频道，也可以直接在 Discord 的频道权限里去掉 bot 的“查看频道”，那样消息根本不会传给 bot。

### `/ds-rp`（所有人）

| 命令 | 作用 |
|---|---|
| `/ds-rp` | 打开编辑框，查看、修改自己在这个服务器的人设卡（只有自己看得到；设成所有服务器共用一张时，就是那一张）；清空编辑框就是删掉这张卡（还能改回上一版） |
| `/ds-rp 操作:改回上一版` | 卡被改坏了（或者删错了）：改回上一个版本，最多能往回改 5 次 |
| `/ds-rp 操作:清空` | 删掉自己的人设卡，连同旧版本，找不回来 |

在私信里用 `/ds-rp`，改的是私信挂的那个服务器的卡（见“十四”；设成所有服务器共用一张时，就是那一张）。

### `/ds-dm`（所有人；服务器里和私信里都能用，回复只有自己看得到）

| 命令 | 作用 |
|---|---|
| `/ds-dm 服务器` | 私信里用哪个服务器的人设、长期记忆和人设卡（列出你和它都在、开着私信的服务器；人设卡设成所有服务器共用一张时，换哪个服务器都是那一张）。在服务器的频道里用、不填，就是这个服务器。换了会清空私信记录，服务器那边的记忆不受影响 |

| `/ds-dm 清空` | 清空私信的聊天记录，让它从头开始 |

## 五、参数说明

管理员可调（`/dsadmin 设置`）：

## 六、读文件

**能读的**：

| 类型 | 说明 |
|---|---|
| 文本、代码 | txt、md、csv、json、py、js、ts、html、日志、字幕……；UTF-8 以外，老的 GBK / Big5 文件也能认，日文（Shift_JIS / EUC-JP）、韩文（EUC-KR）的老文件也行。只有一两行的老编码文件可能认错，认不准时按中文处理 |
| PDF | 读文字，标出页码；没有文字的扫描件改成看前 3 页的图；只限制了打印/复制的 PDF 也能读，有打开密码的读不了 |
| Word / Excel / PPT | .docx、.xlsx、.pptx。表格按行列转成文字，Excel 的日期、百分比按显示格式转换；很大的表只读前面 |

读不了的会直接告诉对方原因：老格式（.doc / .xls / .ppt，另存为新格式就行）、设了密码的文件、压缩包、音频、视频、HEIC/BMP 之类的图片格式等。

**什么时候读**：

- 直接读：叫它的那条消息里带的文件、叫它时回复的那条消息里的文件、同一个人两分钟内刚发的文件。
- 被叫到时按需读：比如“帮小雨看看上面那个 PDF”，模型会先说要打开哪条消息的文件，bot 读完再交给它回答。这样多一次调用，回复会慢几秒。
- 没人叫它时不读文件，只知道有人发了什么文件。例外是 Discord 把太长的消息自动转成的 message.txt，会像普通长消息一样看开头。

**限制**（都在 `config.toml` 的 `[engine]` 里改）：单个文件 20 MB 以内；每个文件最多读 2 万字，太长只读前面，会告诉模型读到了哪里；一轮最多 3 个文件、总共 4 万字（包括它自己要求打开的）。读不了的文件不占名额；一条消息里文件太多、或者额度只够读一部分时，剩下的之后叫它会接着读。确定读不了的文件（格式不支持、坏文件）只说一次，之后不会每次都再试，除非明确让它再打开。

**内容会留在对话记忆里**，所以可以接着问“第三页说了什么”。文件比较大时会多占一些上下文，但之后的请求基本都是缓存命中，费用很低；等它变成旧记录后，会和别的旧聊天一起压成摘要。上下文实在太长时（超过预算两倍、而且超过 10 万 token，比如连着读了好几个大文件）会马上压一次，不等它变旧。

**安全**：所有文件都在单独的子进程里解析，限制了内存（1 GB）、CPU 和时间（30 秒），坏文件或恶意文件最多让这一次读取失败，不会卡住 bot。用 Docker 部署时 bot 以 root 运行，解析子进程会降成 `nobody` 用户，读不到 bot 进程里的 token 和 API key。不用 Docker 时不一定有这一层隔离：以普通用户运行不会降权；以 root 运行时，只有 Python、bot 的代码和装的库别的用户也读得到才会降权（比如库装在 `/root` 下就不会），否则照常以当前用户解析，日志里会提醒一次。`python -m dsbot --check` 会显示有没有降权。文件内容和聊天记录一样，会发给 DeepSeek 处理。

**隐私**：聊天记录和读过的文件内容存在 `./data/` 的数据库里，文件权限是只有 bot 自己能读写（NAS 上别的账号看不到）。

## 七、跨频道记忆

默认每个频道各记各的。在 B 频道它不知道你刚才在 A 频道跟它聊了什么。管理员打开记忆共享后：

- **自动接上**：有人在 B 叫它时，如果这个人 6 小时内在 A 跟它聊过，会把那几句带过来，“刚才说的那个”就能接上。同一段只带一次。
- **按需翻记录**：被叫到时，它知道哪些频道可以翻；需要时（比如“上次在 #游戏 说的那个”）会先去翻那个频道的摘要和最近的记录，再回答。这样多一次调用，慢几秒。

怎么开：`/dsadmin 设置 参数:记忆共享 值:开`，范围可以选本频道、本类别或全服务器，和 `/dsadmin 区域` 一样；值填“默认”就是不单独设置、跟着上一级走。

隐私规则：
- 只有开了共享的频道之间才互通，只在同一个服务器里（连成一组的服务器算一个，见下面的“服务器组”）。跨服务器、bot 主人连通的频道见下面。
- **私密频道**（@everyone 看不到的频道、私密帖子、成人内容频道）就算在“全服务器”范围里开了，内容也不会分享出去。确实要分享，就在那个频道里单独执行 `/dsadmin 设置 参数:记忆共享 值:开`（范围选本频道）。私密频道照样能看到公开频道里共享的内容。
- 不允许回应的区域（`/dsadmin 区域` 禁止的地方）不参与共享。
- 对某个频道执行 `/dsadmin 清空记忆`、关掉它的共享之后，别的频道就拿不到那里的内容了。已经带到别的频道的那几句，还会留在那边最近的记录里，等变成旧记录被压缩时去掉（压缩时只总结那个频道自己的内容）；想马上去掉，就把那边也清空一下。
- 帖子在名单里写成“帖子「标题」”，和频道区分开，群友起个跟频道一样的帖子名也冒充不了频道。
- `/dsadmin 状态` 会显示这个频道能翻哪些频道、自己的内容会不会分享出去。

**跨服务器**（2.6.0 起，默认关）：同一个 bot 在好几个服务器里时，开了“跨服务器”的服务器之间，同一个人跟它聊过的会跟着他走：
- 他在 B 服务器叫它时，带上他最近 6 小时在 A 服务器跟它聊的两段（只有他自己的话和它的回复，别人的话不带），会写明是在哪个服务器的哪个频道聊的。同一段只带一次。
- 他私信里那份私信记忆里不敏感的那些，在开了跨服务器的服务器里也会用上（私信挂着的那个服务器不用开，本来就会用）。
- 只带公开频道里的：私密频道、私密帖子里聊的不带；说了“保密”“别告诉别人”的那段不带。私信的原话只带到私信挂着的那个服务器，不会跨服务器。
- 两边都要开：`/dsadmin 设置 参数:跨服务器 值:开`（只看全服务器这一级）。只开了一边，那边的不会带过来，这边的也不会带过去。私信也一样：私信挂着的那个服务器也开了，私信里才接得上他在别的服务器聊的（私信里聊的会记进那个服务器）。
- 开之前最好跟群友说一声：在这个服务器跟它说的话，可能在另一个服务器被它提起。

**服务器组**（Beta，2.7.0 起，bot 主人用 `/dsowner 服务器组`）：同一群人的几个服务器（比如主服加游戏服）可以连成一组，当成一个服务器来记：
- **共用一份人设卡和长期记忆**：在哪个服务器记下的，组里每个服务器都用得上。`/ds-rp`、`/dsadmin 长期记忆` 看的、改的都是组里那份（组里任何一个服务器的管理员都能改长期记忆）。`config.toml` 里设成了人设卡所有服务器共用一张（`shared_cards = true`，见“十一”）的话，人设卡本来就是共用的：组里只共用长期记忆，连起来、退出都不动人设卡。
- **谁记的谁整理**：长期记忆记着每条是哪个服务器记的（`/dsadmin 长期记忆` 里，组里别的服务器记的会标出来）。退出组时带走的那份也照样记着：再连成一组时，记的那个服务器也在组里的还算它的，不在的算带进来的那个服务器的（那个服务器后来再加进来也不改回去）；没在组里时这边改过的那条，算这边记的。它自己整理记忆时只合并、删改这个服务器记的；别的服务器记的它看不到来龙去脉，不动（要删让那边整理，或者管理员用 `/dsadmin 长期记忆` 删）。有人在聊天里明确叫它改、删哪一条的，照常改。连起来以后记满了（正好 50 条，或者并进来以后超过 50 条）、里面又有别的服务器记的，它不会为了腾地方删条目（有人叫它记，它会说记满了）：整理记忆时只合并、删掉这个服务器自己记的来腾地方，腾不出来就记不进新的，管理员可以用 `/dsadmin 长期记忆` 删几条；超过 50 条时要删到 49 条以内才能再记新的。
- **能互相翻记录**：开了记忆共享的频道，也能翻组里别的服务器里开了共享的频道，名单里写着是哪个服务器；有人在 A 服务器开了共享的频道跟它聊过，到 B 服务器叫它时也接得上。私密频道的规矩不变。让它翻“#大厅（「B」服务器）”这种写明了服务器的，只在那个服务器里找：那边没有（或者没开共享）就是找不到，不会翻成这里同名的频道。
- **私信也一样**：私信挂在组里哪个服务器上，组里的服务器都算“私信挂着的那个服务器”：私信记忆里不敏感的那些、最近私信里聊的几句，在组里的服务器叫它时都会带上。
- **各管各的**：设置、预算、人设、表情包库、点歌还是每个服务器自己的。“跨服务器”照常按每个服务器自己的设置。
- **连起来**：`/dsowner 服务器组 连起来 服务器:A 连到:B`（服务器从弹出的列表里选）。B 已经在组里，A 就加进那个组；反过来 A 在组里、B 不在，就是 B 加进 A 的组（下面说的 A、B 对调，预览里会写明谁加进哪个组）；都不在组里就新建一个组，B 现在的人设卡和长期记忆就是组里的。A 原来的长期记忆并进组里，接在组里原来的后面、重新编号（一模一样的不重复记；超过 50 条也先留着，删到 49 条以内之前不记新的：最好用 `/dsadmin 长期记忆` 删几条）。同一个人两边都有人设卡的，用组里那张，A 那张存成旧版本：本人用 `/ds-rp 操作:改回上一版` 能换成 A 那张，组里那张会存成旧版本，再改回上一版就换回去（换回去以后 A 那张就不留了）；他在组里删掉了卡、而且删得比 A 那张新的，A 那张也只存成旧版本，不会顶上去。
- **退出**：`/dsowner 服务器组 退出 服务器:A`。A 带走一份组里现在的长期记忆，和在 A 出现过的人的人设卡（只在别的服务器的人管不到留在 A 的卡，所以不带）；只在 A 出现过的人，卡跟着 A 走、从组里拿掉。之后各记各的（不会分回连起来之前的样子）。组里只剩一个服务器时组就散了，剩下的那个服务器留着组里剩下的。退出时，频道里附过的、现在不能再带的私信记忆会撤回；已经带进频道记录里的私信原话不撤回（和换私信挂的服务器时一样），旧记录压缩时会去掉。
- **名字**：同一个人在组里几个服务器的昵称可以不一样：卡上记的名字跟着组里第一个服务器的昵称；按名字查卡时，他在组里各个服务器的昵称都认得。在一个服务器里 @ 人，只认在这个服务器出现过的人，按他在这里的昵称。按名字查卡时也先认在这个服务器出现过的人；组里别的服务器有同名的人，查到的会写明他还没在这个服务器出现过，不会安到这里同名的人头上。提示词里“有卡的人”只列在这个服务器出现过的人，别的只说还有人有卡（不说几个：别处多一张卡，这里的提示词不用跟着变）。
- **中途出错**（比如断电、重启）：下次执行 `/dsowner 服务器组` 的随便哪个子命令或者 bot 重启时，会把没做完的接着做完。连组、退组时每一步都等写进磁盘再做下一步，做到一半断电也能接着做完。散掉的组在 `cards.sqlite3`、`memory.sqlite3` 里还剩数据时（多半是只还原了其中一两个文件的备份），它不会删，会在日志和 `/dsowner 服务器组 查看` 里提醒。
- 连起来、退出之前它会先说清楚会怎样（会并进几条记忆、几个人两边都有卡），点“确认”才办；`/dsowner 服务器组 查看` 列出现在有哪些组。`/dsadmin 状态` 里也会写这个服务器和谁连成了一组。
- 连起来之前最好跟各个服务器的人说一声：组里每个服务器的人都可能间接知道别的服务器的事。
- **还是 Beta**：刚做好，可能还有没发现的问题。连起来之前最好先备份 `data/` 文件夹（先停止项目再复制，见“十一”）。要换回 2.7.0 以前的版本，先用 `/dsowner 服务器组 退出` 让组里的服务器一个个退出、直到组散掉（旧版本不认服务器组，看不到组里共用的人设卡和长期记忆）。

**连通频道**（Beta，2.8.0 起，bot 主人用 `/dsowner chatsync`）：把几个服务器（也可以是同一个服务器）的文字频道连通，几个频道共用一份聊天记录：
- **当成一段对话**：在哪个频道叫它，它都看得到连通的频道里聊过的（记录里每段写明是哪个服务器的哪个频道），消息编号、更早的摘要也是同一份。被叫到时，别的连通频道里还没进记录的消息会先补进来（不另外问模型、不花钱，也不在那边回话），所以“那边刚才在聊什么”它接得上；那边叫它的消息留给那边，它会在那边回。补进来的消息要是让这一轮被 DeepSeek 拒了（比如触发内容审核），那几条换成一句“没记下”，不会卡住几个频道（见“十七”）。
- **只在这里说话**：它只在被叫（或者主动发言）的那个频道说话、加表情，不会跑到别的频道去；回应别的频道的消息时就在这里说（挂不成回复：Discord 只能回同一个频道的消息）。别的频道的人在 Discord 上看不到它在这里发的消息，不过它在这里说的话也在共用的记录里，在那边可能被它提起。
- **各管各的**：人设、设置、预算、表情和贴图、人设卡、长期记忆还是每个服务器（或者服务器组）自己的。@ 人只认这个服务器的人；提到别的服务器的频道（记录里写成“#大厅（「某某」服务器）”），不会换成这里同名频道的链接。整理记忆时，每段聊天按它在哪个服务器，记进那个服务器的人设卡和长期记忆；几个频道的聊天分开整理，一个服务器那部分出错、超了预算，不耽误别的服务器的，整理过的断开、重启以后也不再整理。
- **保险**：只有 bot 主人能连；只能连公开的文字频道（私密频道、成人内容频道、帖子、私信都不行）。连通、断开时它会在相关的频道各发一条说明，让大家知道。
  - 连通之前各频道的旧聊天不给别的频道看：每个频道自己还记得（只给它自己看个大概），连通那一刻还没进记录的闲聊也记在它自己那份里。
  - 私信里的事不带进连通的频道（私信记忆、刚才私信里聊的几句都不带）。
  - **跨服务器连通时**（几个频道不全在同一个服务器；连成服务器组的算一个），共用的记录里只放这几个频道里说的：翻别的频道的记录、按名字查人设卡这里不能用，别的频道、别的服务器的近况也不带进来，@ 人只认在这个频道说过话、被 @ 过的人；人设卡只在设成所有服务器共用一张（`shared_cards = true`，见“十一”）时才附上，各服务器一张的不附（附了那边就看到了），这里也不改人设卡（请群友自己用 `/ds-rp` 改）；它改长期记忆时，记下的回话里不留那一条的原文（长期记忆是每个服务器自己的）；语音频道在放什么会写明是哪个服务器的。同一个服务器里的几个频道连通时，翻记录、近况、人设卡照常。
  - **变成跨服务器时**：原来都在同一个服务器（或者服务器组）里的组连进了别的服务器的频道，或者组里的服务器退出了服务器组，共用的记录里只有原来那边能看的内容（别的频道带来的近况、能翻的频道名单、翻到的记录、按名字查到的人设卡；人设卡各服务器一张时，连同附着的卡和它自己写过的卡）会先拿掉，连通前的预览会写明。原来只有一个服务器时写的“语音频道在放什么”也补上是哪个服务器的。组里的频道还在一个服务器组里、可是组里原来有的服务器退出了的话，也一样整份查一遍（那个服务器带进来的分不出是哪几条，已经断开的频道留下的那几段也算）。
  - 服务器组里的几个服务器的频道连通时：语音频道在放什么也写明是哪个服务器的；服务器组以外的服务器的近况，要这几个服务器都开了“跨服务器”才带进来。连进来的频道所在的服务器原来不在这个连通组里、又没开“跨服务器”的话，共用的记录里写着是哪个服务器的近况（服务器组里的也算：分不出当时是组里还是组外的）会先拿掉（连通前的预览会写明）。
  - 连通以后频道被改成私密频道（或者成人内容频道）：连通暂停，它不看那里的消息，直到 bot 主人断开连通、或者频道改回公开（`/dsadmin 状态`、`/dsowner chatsync 查看` 里会写）。说明、列表、给它看的记录里只写连通时的频道名，不显示它现在叫什么。这时在那里改过的消息，共用的记录里那一行当成删了（改成了什么不带进去；还没处理的那条也不再处理）。
- **连通**：`/dsowner chatsync 连通 频道:A 连到:B`（频道从弹出的列表里选，能按服务器名、频道名筛选；也可以用 # 选这个服务器的频道，或者直接打频道名：只有一个叫这个名字的就是它，有几个同名的会请你从列表里选）。B 已经连通了，A 就加进 B 那一组（反过来也一样）；都没连通就新建一组。一个频道只能在一组里。加进已经有的组时，A 也看得到组里已经共用的记录（连同更早的摘要，已经断开的频道连通期间说过的也算），预览和组里各频道收到的说明都会写明。
- **断开**：`/dsowner chatsync 断开 频道:A`。A 把共用记录里自己这次连通期间的那部分（A 里说的、它在 A 回的）带回去接着用；别的频道说的不带走，共用记录更早的摘要也不带走（里面有别的频道的事）。组里还剩的频道照样共用（A 连通期间说过的，它们还记得；要让它们也忘掉，在 A 用 `/dsadmin 清空记忆`）。组里只剩一个频道时组就散了，那个频道也拿回自己那部分，共用的记录连同摘要删掉。
- **清空记忆**：在连通的频道里 `/dsadmin 清空记忆`，只清掉这个频道在共用记录里说过的话（连同共用的摘要：里面分不开）和它连通之前的记录；别的频道说的不动，之后照样连通。以前连通过的频道清空时，留在那个组共用记录里的它那部分也一起删掉（它说的已经压进那个组的摘要的话，连同摘要）。会先等正在回的话说完。删消息、改消息照常同步进共用的记录（断开以后也是；频道变成私密的、被 `/dsadmin 区域` 关掉了的话，改过的消息在共用的记录里当成删了，它自己的记录照常改：连通期间说的，断开拿回来以后照改过的写）。
- **费用**：几个频道的话都在一份记录里，记录长得快、压缩得勤，每次调用带的内容也多，费用会比各聊各的高一些。
- `/dsowner chatsync 查看` 列出现在有哪些连通组；`/dsadmin 状态` 里也会写这个频道和哪些频道连通了（跨服务器连通时还会写哪些不能用）。
- **还是 Beta**：连通之前最好先备份 `data/` 文件夹（先停止项目再复制，见“十一”）。要换回 2.8.0 以前的版本，先把连通的频道都断开（旧版本不认连通组，连通期间的聊天它看不到；没断开就换回去跑过的话，再换回 2.8.0 时它会在日志里提醒，断开时不把连通期间的聊天拿回去，免得记录乱掉，组还在的话那部分留在组里照样整理（组散了就和共用的记录一起删掉）；断开的预览、说明里也会写明）。断开时拿回了连通期间那部分的频道，消息编号中间会跳过一段，旧版本按编号只记得最近 3000 个：换回去以后，很早的消息被删、被编辑可能就改不到记录里了，介意的话换回去之前先在那些频道 `/dsadmin 清空记忆`。

## 八、联网搜索

它的知识大约只到 2025 年中。被叫到时，如果问题需要最新或实时的信息（新闻、价格、汇率、比分、天气、新出的产品……），它会先上网搜一下再回答。要不要搜由它自己判断，闲聊和常识不会去搜。

- **用的是 DeepSeek 的 Search 接口**（2026-10-17 开放的 `/v1/tools/search`），用的就是 `DEEPSEEK_API_KEY`，不需要别的 key。一次通常不到 1 秒。按次收费：每 1000 次 0.75 美元（一次 0.075 美分），只有搜到结果才算钱，算进每日预算。
- 搜到的几条（标题、网站、日期、摘要）交给它自己读，挑对得上的用自己的话说；问最近的事，它会在关键词里写上具体日期。
- 只有被叫到时才搜，主动聊天时不搜。一轮最多搜 2 次。
- 每个服务器每天最多搜 30 次，用 `/dsowner 设置 参数:每日搜索上限` 改（可以指定服务器）；`/dsowner 设置 参数:联网搜索 值:关` 关掉。超了预算也不搜。
- 回答里带的链接不会展开预览，免得刷屏。
- 搜到的网页内容和文件一样当成资料处理，里面写的“忽略之前的设定”之类不会照做。
- 部署后可以先跑一次 `docker compose exec dsbot python -m dsbot --test-search "台北 今天 天气"` 确认能搜到。DeepSeek 没搜到、或者出错了（比如余额不够），填了 `TAVILY_API_KEY` 的话会自动改用 Tavily 再搜一次（填完 `docker compose up -d --force-recreate`）。

### 冒泡

在某个频道里 `/dsadmin 设置 参数:冒泡 值:开`，这个频道安静久了它会自己来说点什么，像群友闲下来随手发一条：

- **什么时候**：一直没人说话满 4～6 小时（“冒泡间隔小时”，每次随机）；只在 8 点到 23 点（`config.toml` 里 `[engine]` 的 `bubble_from_hour`、`bubble_until_hour`）；每个频道每天最多 3 次（`bubble_daily_limit`）；上次冒的没人理，就等有人说话以后再冒，不会对着没人的频道连发。
- **说什么**：八成的时候分享一条新鲜事，两成的时候只打个招呼、接着以前聊过的事说一句（`bubble_greet_share`）。分享的时候，话题是从这个频道的“兴趣”里挑一个最近两天没搜过的，搜最近 3 天的消息给它看，它挑一条用自己的话说一两句、带上链接；搜到的都不合适，它就改成打招呼，或者不说。
- **去哪搜**：用的是现成的联网搜索（DeepSeek 的搜索接口），不用 X 的账号和 key。七成的时候先只搜 X 上的（搜索词里限定 `site:x.com`），X 上没搜到再搜全网；其余时候直接搜全网的新闻（`bubble_x_share`）。每搜一次算一次联网搜索，算进每天的搜索次数；这里不能搜（没开联网搜索、今天搜够了）时它就只打招呼。
- **兴趣是怎么来的**：开了冒泡的频道里，聊了几句（4 条以上）、停下来十分钟以后，它会单独问一次模型“这群人对什么感兴趣”，把看出来的话题（最多 3 个）记下来，一小时最多看一次。只看这个频道自己的聊天，不看人设卡、私信记忆和别的频道带来的内容；发给搜索服务的只有话题那几个词。`/dsadmin 兴趣 查看` 看得到，`添加` 可以自己加，`删除` 掉它自己看出来的话题会记成“不让搜”。它自己看出来的最多留 20 个，久没用的先去掉。
- **有人接话**：它冒泡以后有人说话，它会照“聊起来就跟着”的规矩接着聊（这个频道没开主动发言也接）；别人叫它照旧马上回。
- **花费**：看一次兴趣是一次很小的模型调用；冒一次泡是一次模型调用加一两次搜索（搜到了才算钱，一次 0.075 美分）。一个频道一天下来通常不到 1 美分。
- 搜到的东西可能不准、不相关或者过时：它被要求挑可靠的、不合适就不发，但没法保证每条都合适。不放心的话题用 `/dsadmin 兴趣 删除` 拦掉，或者关掉这个频道的冒泡。
- 冒泡只认在那个频道里开的设置（开在全服务器、类别上不算）。连通的频道（`/dsowner chatsync`）暂时不冒泡。`/dsadmin 状态` 里有一行冒泡的情况：今天冒了几次、下一次大概什么时候。重启以后，安静了多久从启动那一刻重新算。

## 九、读链接

群友发的链接，它分两种情况看：

- **平时**（包括主动聊天）：只看 Discord 自己生成的链接预览：标题、作者、开头一段描述，预览图也会看（排在群友发的图后面）。不额外花钱。
- **被叫到时真的打开**：叫它的那条消息里的链接、叫它时回复的那条消息里的链接、同一个人两分钟内刚发的链接，会直接打开再回答；“帮我看看上面那个链接”这种，它会自己去打开（和看文件一样，多一次调用，慢几秒）。B站的视频链接（包括 `b23.tv` 短链接）不打开，只看 Discord 的预览（标题、简介、封面）：视频它本来就看不了，要放歌就叫它点歌（见“十三”）。
  - **X（推特）的推文**：走 [FxTwitter](https://github.com/FxEmbed/FxEmbed) 的免费接口，不用账号、不用 key。能拿到全文、引用的推文、投票、社区笔记和图片（图片交给它看图）。视频只看得到时长和封面。
  - **别的网页**：先交给 DeepSeek 的 Fetch 接口（`/v1/tools/fetch`）去读，用的也是 `DEEPSEEK_API_KEY`。读到了按次收费（每 1000 个 0.75 美元，读不到不算钱），算进每日预算。DeepSeek 读不了的（PDF、有的网站不让它看），填了 `TAVILY_API_KEY` 的话再交给 [Tavily](https://tavily.com) 试一次（每打开 5 个网页算 1 次额度，免费每月 1000 次）。
  - **要登录才能看的网站**（Threads、IG、Facebook、小红书……）多半打不开，它会照实说只看到了预览，不会照着标题瞎猜。
- 每个链接最多读 4000 字，一轮最多打开 3 个，每个服务器每天最多打开 100 个（都在 `config.toml` 的 `[engine]` 里改）。打不开的链接（要登录、被删了）只说一次，之后不会每次都再试，除非明确让它再打开。超了每日预算时不用 DeepSeek 读网页（它按次收费），推文和 Tavily 照常。
- **安全**：NAS 自己不去打开网页。推文由 FxTwitter 读，网页由 DeepSeek（或 Tavily）的服务器读，所以群友发的链接碰不到你家的内网，对方网站也看不到你家的 IP。只有推文里的图片由 bot 自己下载，而且只从 X 的图片服务器下载。图片、视频、压缩包、Discord 自己的链接、内网地址（192.168.x.x、xxx.local 之类）不会被当成网页打开。网页里写的“忽略之前的设定”之类，和文件一样只当资料。
- 推文和网页的内容会经过 FxTwitter / DeepSeek / Tavily，再和聊天记录一样发给 DeepSeek。
- 开关：`/dsowner 设置 参数:读链接 值:关`。部署后可以先试一下：`docker compose exec dsbot python -m dsbot --test-link 网址`。

## 十、发表情包和图

它可以像群友一样斗图：

- **表情包库**（不花钱）：
  - **通用库**：在 NAS 上项目文件夹的 `data` 里新建一个 `表情包` 文件夹，把图放进去，所有服务器都能用。文件名就是表情包的名字，它是看名字挑图的，所以名字要写清楚意思，比如 `熊猫头-无语.png`、`猫猫-震惊.gif`。放进去就生效，不用重启。
  - **每个服务器自己的库**：管理员用 `/dsadmin 表情包 上传 图片:（附上图片） 名字:熊猫头-无语`；`/dsadmin 表情包 查看` 看全部，`/dsadmin 表情包 删除` 删掉（「名字」一栏会列出这个服务器的表情包）。同名时这个服务器自己的优先。存在 `data/服务器表情包/` 里。
  - 支持 PNG、JPG、GIF（动图也行）、WebP，每张 8 MB 以内，每个服务器最多上传 300 张。名单放在 system prompt 里，最多列 80 个（`[engine]` 的 `meme_list_limit`）；表情包有增删时，那个服务器的缓存会失效一次。
- **上网找图**（要 `TAVILY_API_KEY`）：库里没有合适的、又真的想发图时，它会上网找。找到的几张候选图先给它看，它自己审核一遍：
  - 跟话题对得上、看得清楚才发；色情、血腥、恶心的，带别人个人信息的（聊天截图里的名字、头像之类），被水印或广告盖满的都不要；都不合适就不发。Tavily 那边也开了安全搜索。
  - 网上找到的动图不发：它只看得到第一帧，后面的画面审核不了。动图表情包可以放进表情包库。
  - 审核靠它自己看图，没办法保证百分之百准，比如图里的小字、梗图里的暗喻可能看漏。所以有次数上限和冷却，也能随时关掉。
  - 每次找图用掉 1 次 Tavily 额度，加上让它审核的那一次调用（通常不到 0.1 美分）。每个服务器每天最多 10 次（`/dsowner 设置 参数:每日找图上限` 改），同一个频道 10 分钟最多找一次（`[engine]` 的 `image_cooldown_seconds`）。
  - 发出去的是原图（作为附件上传，bot 要有“附加文件”权限）。只有透明底的图会先铺上白底、存成 JPEG 再发，和它审核时看到的一样，免得深色主题里冒出它没看到的东西。超过 8 MB 的图不下载。
  - 下载候选图时只连公网地址、不走代理；内网地址、奇怪的 IP 写法一律不连，跳转也会重新检查。
- 主动聊天时也能发（和说话一样算开了口），被叫到时也会用；大多数时候它还是用文字。
- 关掉：`/dsadmin 设置 参数:发图 值:关`，表情包和上网找图都不发了（范围可以选本频道、本类别或全服务器）。
- 部署后可以先试一下：`docker compose exec dsbot python -m dsbot --test-image "水豚"`，候选图会存到 `data/找图测试/`，看完可以删掉。

## 十一、人设卡和长期记忆

它会记住每个群友，也会记住这个服务器发生过的事：

- **人设卡**（每个服务器里每人一张，最多 1600 字；也可以设成所有服务器共用一张，见下面）：记这个人自己说的、关于自己的事，比如怎么称呼他、他给自己定的设定（自称猫娘、在戏里的角色）、喜好和雷点、常玩的梗。这个人说话时，它会把卡附在聊天记录里，自然地用上：按卡上的称呼叫人、配合他的设定。聊到不在场的人时，它也能去查那个人的卡。
- **长期记忆**（每个服务器一份，最多 50 条，每条 200 字以内）：约定、重要的事、长期的梗、正在进行的剧情。每个频道它都看得到。
- 几个服务器连成一组时（见“七”的“服务器组”），组里共用一份人设卡和长期记忆。

**所有服务器共用一张人设卡**（2.7.0 起，默认关）：同一个人在好几个服务器里时，想让他的卡跟着他走，在 `config.toml` 的 `[bot]` 里把 `shared_cards` 改成 `true`，再重建容器（`docker compose up -d --force-recreate`）。改之前最好先停止项目、备份 `data/`：改回 `false` 也不会变回原来的样子（见下面）。之后：
- 每个人只有一张卡，在哪个服务器（和私信里）用的、改的都是这一张：在 A 服务器叫它“记住我是猫娘”，到 B 服务器它也知道。`/ds-rp` 看的、改的、清空的也是这一张（清空就是所有服务器都没了）。长期记忆不受影响，还是每个服务器（或者服务器组）一份。
- **改的时候**：重启时自动把各服务器的卡并成每人一张。几个服务器各有一张的，用最近改过的那张；别的存成旧版本，本人用 `/ds-rp 操作:改回上一版` 能换过去（现在这张会存成旧版本，再改回上一版就换回来；换回来以后，换过去的那张就不留了）。旧版本一共留 5 个，别的服务器的卡排在前面。他在哪个服务器清空了卡，那边那张就不会并回来；别的服务器里还有的照样算（比如退组、改回每个服务器一张时复制过去的那份，之后是各管各的）。所有服务器共用时清空的、bot 主人删掉的，哪里的都不会并回来。日志里会写并了几个人的卡。
- **名字和查卡**：卡上的名字不再跟着昵称变；他在各个服务器的昵称都记着。在一个服务器里 @ 人、按名字查卡、提示词里“有卡的人”，都只认在这个服务器出现过的人，按他在这里的昵称（他在别的服务器的昵称不算）：别的服务器的人在这里查不到，免得一个服务器的人打听到另一个服务器的人。只在私信里跟它聊过（私信挂在这个服务器）的人不知道在这里叫什么，按卡上的名字认，查到的会写明。这个服务器连成了组的话，在组里别的服务器的频道里出现过的人也查得到，查到的会写明他还没在这个服务器出现过（在那边只在私信里出现过的不算）。
- **隐私**：卡上可能有他在别的服务器、在私信里说的事，在这个服务器也会用上（它会注意别把别处的私事拿出来说，整理记忆时只跟这个服务器有关的会写明是这里的）。打开之前最好跟大家说一声。哪个服务器用 `/dsadmin 设置 参数:人设卡 值:关` 关掉了，那里照样不用卡。
- **改回 `false`**：重启时把每个人的卡（连同旧版本）复制回他出现过的每个服务器（连成一组的放在组里）；之后各改各的。不会变回打开之前的样子：原来几个服务器各有一张的，现在每个服务器拿到的都是同一张，原来那几张顶多还留在旧版本里（旧版本一共只留最近 5 个，共用期间卡多改几次就挤掉了，它整理记忆时改的也算）。没在任何服务器出现过的人（极少见，比如在各服务器都把卡清空了、只剩旧版本的），卡和旧版本先留在共用的那份里，再改成 `true` 时还在。
- 这个设置记在 `cards.sqlite3` 里，改了 `config.toml` 要重启才换过来；换到一半出错，或者启动时接着做（检查）上次的连组、退组出错了（比如数据库正被别的程序占着），都还按原来的方式用（日志里会写），下次重启再换。要换回 2.7.0 以前的版本，先把它改回 `false`、重启一次，日志里有“人设卡：改回每个服务器一张”了再换（旧版本不认共用的卡，会以为大家都没有卡）。

**怎么记下来**
- **当场记**：叫它说“记住我是猫娘”“以后叫我老大”，它会改你的人设卡；说“记一下，我们每周五晚上九点打副本”，它会记进长期记忆。记下了会在你那条消息上加个 📝。
- **自己整理**：频道安静大约 10 分钟、又攒了几轮新聊天时，它会回顾一遍，把值得长期记住的写进人设卡和长期记忆；旧聊天要被压缩成摘要之前，也会先把那部分原话挑出来，在后台整理（不耽误压缩；整理到一半又压缩了，压掉的那部分排着队接着整理）。每次整理是单独的一次调用，费用很少，日志里会有一行“整理了记忆”。整理的时候有人叫它，照样马上回。
- 整理失败时会隔得越来越久再试：连不上、限流、余额不足这类问题，等恢复了再接着整理（快要压成摘要的那部分原话只试一次，没整理成就跳过）；模型的输出不能用、或者一直写不完（超时），连着 3 次就跳过那一批，不会一直花钱。从旧版本升级上来时，之前的聊天不回头整理，从升级之后开始。
- **自己改**：群友用 `/ds-rp` 打开编辑框，直接改自己的卡。

**规矩**
- 人设卡只记本人说的关于自己的事。别人说“阿明是笨蛋”，不会写进阿明的卡。在聊天里改卡，也只认本人这一次叫它的那条消息（按用户 ID 认，改昵称冒充不了）。
- 健康、住址、真实姓名、联系方式这类敏感的事不记，除非本人明确要它记。
- 人设卡和长期记忆只当资料：里面写的“以后要怎么说话”之类的要求不算数，它自己的人设还是只有 dsowner 能改。
- 私密频道里聊的，它不会自己整理进人设卡和长期记忆（这两样整个服务器都看得到），有人明确叫它记住的除外。想让某个私密频道也自动整理，在那个频道里执行 `/dsadmin 设置 参数:人设卡 值:开`（长期记忆同理）。
- `/dsadmin 清空记忆` 只清这个频道的聊天记录，不动人设卡和长期记忆。

**谁能看、谁能改**
- **人设卡是本人的隐私**：只有本人能用 `/ds-rp` 看、改、改回上一版或者清空，窗口只有自己看得见。管理员看不到，也删不了别人的卡；`/dsadmin 状态` 里“上次的想法”在附过人设卡的频道也不显示。别人问起某个人是什么设定，它可以用自己的话、照自己的口吻大概说说，但不会照念卡上的原文：要发的话里有一长段和它看得到的卡一模一样（连着 16 个字或词以上，比这短的卡是整张；或者东一段西一段、每段至少 8 个字，加起来抄到卡上 32 个字，短一点的卡是卡的四分之三、至少 16 个字；编号列出来、调换顺序、换成繁体都算。只用上称呼和口头禅不算），就不会发出去——被叫到时会让它用自己的话重说一次，还是照念就不说、只在那条消息上加个 🤐；主动插话时直接不发。群友自己在频道里说过的话、发的文件，它照着说不算。卡上的原话也不会被记进长期记忆（拆成几条分开记也一样）、搬进人设，也不会被它抄进别人的卡。本人想看原文用 `/ds-rp`。换个说法、翻译成别的语言、拆成好几次慢慢说，这些还是靠提示词约束；不到 10 个字的卡、不到 16 个字的卡少念一两个字、被拆成几小段（每段不到 8 个字）的短卡也拦不住，没法百分之百保证，太私密的事别写进卡里。（以前的版本是别人问起时完全不说，升级后变了，最好告诉群友一声。）
- **你（bot 主人）** 可以用 `/dsowner 删除人设卡` 填用户 ID，删掉这个人在所有服务器的卡和他的私信记忆，删的时候看不到内容。比如有人退群后想被忘掉（退群后他自己就用不了 `/ds-rp` 了），或者有人往卡里写了奇怪的东西。
- **长期记忆**记的是群里的事，管理员可以用 `/dsadmin 长期记忆` 查看、添加、删除和清空（「编号」一栏会列出每条的内容，输入几个字能筛选：删除时选要删的那条；条目多、列表里每条截短了，查看时选上编号能看那一条的全文）。
- 每张人设卡保留最近 5 个旧版本，给“改回上一版”用。在聊天里叫它忘掉、或者清空编辑框，旧版本还留着；`/ds-rp 操作:清空` 和 `/dsowner 删除人设卡` 连旧版本一起删。
- 卡删掉之后：那个人下次说话时，它会被告知卡已经删掉、之前附过的那份别再用；整理记忆时也不会拿删掉之前的聊天把卡重新写回来。最近的聊天记录里已经附过的那份，会在记录被压缩时一起去掉。

**存在哪里、怎么备份**

三份数据各存一个文件，都在项目的 `data` 文件夹里，只有 root 能读写：

| 内容 | 文件 |
|---|---|
| 聊天记录（连通频道共用的那份也在这里）、设置、花费记录、服务器组、连通组 | `data/dsbot.sqlite3` |
| 人设卡 | `data/cards.sqlite3` |
| 长期记忆、私信记忆 | `data/memory.sqlite3` |

- 备份或者搬到新的部署：先停止项目，再复制对应的文件。SSH 用 `sudo cp`，或者用 Hyper Backup 备份整个项目文件夹。
- 想让它忘掉所有人设卡或者长期记忆：停止项目，删掉对应的文件。
- 文件位置可以在 `config.toml` 的 `[bot]` 里改。
- 服务器组共用的人设卡、长期记忆也存在 `cards.sqlite3`、`memory.sqlite3` 里，哪些服务器在哪个组记在 `dsbot.sqlite3`：用过服务器组以后，搬家、还原备份时三个文件要用同一时刻的一起搬、一起还原；不要单独删掉 `dsbot.sqlite3`，也不要只还原 `cards.sqlite3`、`memory.sqlite3` 其中一两个（想让它忘掉人设卡或长期记忆，照上面删掉对应的文件没问题）。对不上时，多出来的组的数据它不会删，会在日志和 `/dsowner 服务器组 查看` 里提醒。

**开关**：`/dsadmin 设置 参数:人设卡 值:关`、`/dsadmin 设置 参数:长期记忆 值:关`，范围可以选本频道、本类别或全服务器。关掉的地方不附卡、不整理，也不会写入。

## 十二、角色扮演、表情、聊天里改人设

**角色扮演**：群友拉它演戏（“来演个戏，你是酒馆老板”）时，它会照着设定演、跟着剧情走，回复可以比平时长，动作和神态写在斜体括号里，比如 *（擦着杯子抬头）*。最近的聊天跟那场戏没关系了、或者有人说不玩了，它就回到平时的样子；带“场外”“OOC”的话算戏外闲聊，戏不会因此结束。演完一直出不了戏的话，`/dsadmin 清空记忆`。

角色卡之类的长设定：单条消息进上下文前最多 1800 字（`config.toml` 里的 `max_chars_per_message`）。更长的就做成 .txt 发出来，在同一条消息里 @ 它，会整份读（最多 2 万字）。

**加表情就够的时候不硬回**：被叫到时，如果对方的话不需要它说什么（道谢、晚安、收到、哈哈哈、只是给它看个东西），它会只加个表情；好几个人同时叫它，也不一定每条都回话。

**@ 人和频道**：它话里写 `@名字 `、`#频道名 `（名字后面空一格），发出去之前会换成真的 @ 和频道链接。
- **能 @ 的人**：最近在这个频道说过话的、最近消息里被 @ 过的、这个服务器有人设卡的；都对不上的话，再按名字的开头在服务器成员里找一次（Discord 按用户名和服务器昵称找）。同名分不清的、它自己、别的 bot，保持普通文字。@everyone、@here、身份组永远不会变成真的 @。
- **名字后面要隔开**（空格、标点或者结尾）才会换：“@阿明 快上线”会换，“@阿明快上线”不换。这样“@大家”不会被当成 @ 一个叫“大”的人。代码块和网址里的 @（比如 `youtube.com/@xxx`）也不换。
- **什么时候真的提醒**：只在有人叫它的时候；它这一次回话（分几条发也算一次）最多提醒 3 个人；同一个人 5 分钟内最多被它提醒一次；整个服务器 10 分钟内最多提醒 10 次。其他时候 @ 只显示成蓝字，不发通知。它主动插话时也只显示、不提醒。
- 频道链接：这个服务器里它看得到的频道和帖子。纯数字的（比如 `#12`，那是它看的消息编号）不换。写明了是哪个服务器的频道（“#大厅（「B」服务器）”“「B」服务器的 #大厅”）：B 是这个服务器就照常换；B 是 bot 在的别的服务器、组里的、或者最近有人在那边跟它聊过的服务器，就不换，免得链到这里同名的频道。只写了“「B」#大厅”（没写“服务器”）的，B 是 bot 在的别的服务器才不换，「」里是别的字（“「必看」#公告”）照常换。认不出 B 是哪个服务器的（比如游戏里的“生存服务器”）：这个服务器没连组、没开跨服务器、不共用人设卡，这个频道也没和别的服务器的频道连通时照常换；不然（它看得到别的服务器的名字，卡上、共用的记录里也会写）就不换。这里和组里的服务器（开了跨服务器时，还有也开了跨服务器的服务器）同名、分不出是哪个时，也不换；连了组、开了跨服务器或者共用人设卡时，它自己截短（带着“…”）或者截到 40 字的这里的名字，bot 知道的别的服务器也对得上的，也不换（聊天里给它看的、截到 60 字的照常换）。

**消息被删除、被编辑**：
- 还没轮到它处理的：删了就不看了，那条是在叫它的话就不回；改了就看改过的。改的时候补上 @它，算叫它；把 @ 删掉，就不回了。
- 它正在想怎么回的：删了就不回那条、也不给那条加表情；人设卡也不照那条改。
- 已经在它聊天记录里的：
  - **删除**：那一行变成“（这条消息已删除）”，带的图、文件和链接内容一起拿掉。整理记忆、压缩成摘要、别的频道来翻记录时都看不到了。
  - **编辑**：最近几轮里的消息，直接换成新内容，标上〔已编辑〕；更早的消息，记录不动，下一轮附一句“（#12 阿明 改了这条消息，现在是：……）”。
  - 别的 bot 一直在改自己的消息（播放进度、投票、倒计时之类）：还没处理的照样更新，已经在记录里的不跟着改。
- 为什么编辑早的消息不直接改：改写旧记录会让那一处之后的缓存全部失效，有人一直改很早的消息就会一直多花钱。删除总是直接改（隐私优先），每删一条最多多花不到 1 美分（上下文满 3 万 token、删的是最早那条的时候）。
- 所以**想让它彻底忘掉某条消息里的内容（比如不小心发了手机号），请删掉那条消息，不要只是编辑**：编辑较早的消息时，旧内容还留在它的记录里，只是会告诉它以新的为准。
- 收不回来的：已经压进摘要的、已经写进人设卡或长期记忆的、它自己的回复里复述过的、已经带到别的频道去的近况。人设卡本人可以用 `/ds-rp` 改，长期记忆管理员可以用 `/dsadmin 长期记忆` 删。它自己发的消息被删掉，不影响它的记录。

**服务器表情和贴图**：它知道这个服务器有哪些自定义表情和贴图（名单放在 system prompt 里，最多列 100 个表情、30 张贴图，在 `[engine]` 的 `emoji_list_limit`、`sticker_list_limit` 改）。回复里写 `:名字:` 会变成那个表情，加表情反应也能用服务器表情，也能单独发一张贴图（和说话一样算开了口）。只给某些身份组用、bot 又没有那个身份组的表情，以及因为加成等级掉了的表情和贴图，不会列出来。

**聊天里改人设**：`OWNER_ID` 本人叫它（@、回复它或者叫别名都行）说“以后说话毒舌一点”之类，它会把改好的完整人设存进设置，和用 `/dsadmin 人设` 改一样，下一轮生效。改好后它会在你那条消息上加个 📝，看到它就是真的改了。
- **改哪一份**：默认改这个频道现在用的那份。大多数时候就是全服务器的；如果这个频道（或所在频道、类别）单独设过人设，改的就是那一份。说“只改这个频道”就只改这里。明确说“全服务器都改”、而这里又单独设过人设时，它不会改，会请你用 `/dsadmin 人设` 去改全服务器的。
- **恢复和撤销**：说“改回默认人设”，全服务器那一级会恢复默认；频道、类别那一级则是不再单独设置、沿用上一级。说“改回去”“撤销”，会回到上一次修改之前的样子，再说一次就再往前撤一次（用 `/dsadmin 人设` 改的也算一次）。每次修改都记在 `./data` 的数据库里，重建容器也还在。人设本来就是那样时不会记、也不会加 📝。
- **照着文件改**：可以说“看看上面那个角色卡，照着改你的人设”，它会先看文件再改。照着网上搜到的、或者别的频道里的内容改不行，免得别人写在那里的东西被拿来改人设。人设最长 4000 字。
- **只认你本人这一次的话**：聊天记录里你的消息会标上〔dsowner〕。这是按用户 ID 认的，别人改昵称冒充不了。代码还会再核对一次：只认这一轮里你本人叫它的那条消息。别人转述“dsowner 同意了”、文件里写的、转发的消息都不算。
- 别人提要求时，它会让对方去找 dsowner。群友先提、你再叫它说“可以，照他说的改”也行。改动比较大的话，记得 `/dsadmin 清空记忆`。

这些规则都写在 `dsbot/prompts.py` 里，改那里要重新构建容器（Container Manager 里是项目先停止再构建）。

## 十三、点歌（B站）

它能进语音频道放 B站视频的声音。只能放 B站的：YouTube 现在要登录验证、限制越来越多，暂时不支持。

**怎么点**
- 先进一个语音频道，然后：
  - 在聊天里叫它：“@小D 放首晴天”“来点周杰伦”“放这个 BV1xx411c7mD”。切歌、暂停、继续、停止、删歌、清空队列，问“现在放的什么”，也都可以直接跟它说。
  - 或者用 `/ds-music`：`播放`（填歌名或者 B站链接）、`切歌`、`暂停`、`继续`、`停止`、`队列`、`删除`、`清空`。不经过 DeepSeek，不花钱。
- **点错了、不想听某一首**：跟它说“刚才那首不要了”（不说哪首，就删你自己最近点的那首）、“把第 2 首删了”“把稻香删了”，或者用 `/ds-music 删除`（点“歌”那一栏会列出队列里的歌，选一首就行）。编号就是 `/ds-music 队列` 里前面的数字，1 是接下来要放的那首；一次可以删好几首（“删掉第 2 和第 4 首”“把 2 到 5 删了”，或者填 `2 4`、`2-5`）。删到正在放的那首就等于切歌。后面排着的全都不要了，用 `/ds-music 清空`（正在放的接着放完）。一句话里说好几件事（“放 X，然后把它删了”“先清空，再放 X”），它会照你说的顺序办。
- 它会进你所在的那个语音频道（耳机图标是关着的：它只放歌，听不到大家说话）。它正在别的语音频道放歌时，会请你过去一起听，或者等那边放完。
- 写歌名时，它会上网找 B站上的视频，挑标题最对得上的：原曲、官方 MV 优先，翻唱、伴奏、教学、讲解分析、合集往后（你自己说要那种的除外）。DeepSeek 和 Tavily 都没找到、改用 B站自己的搜索时，B站的搜索结果没有标题，就照 B站的排序。找错了就直接贴 B站链接（`bilibili.com/video/…`、`b23.tv/…` 短链接，带不带 `https://` 都行；只写 BV 号、av 号也行），或者把歌手说清楚。分 P 的视频放链接里那一 P。
- 不限时长，不限队列长短。直播不放。
- 第一首要先下载才能放，一般几秒；很长的视频要久一点，它会先说“正在下载”，下好了自己开始放。每个服务器只先下载接下来的两首，后面的轮到了再下载，所以队列再长，NAS 上也只存着几首。

**谁能操作**
- 谁都能点歌（要在语音频道里）。
- 切歌、暂停、继续、停止、删除、清空：在它放歌的那个语音频道里的人都能用（也能删别人点的歌），不在里面的不行。

**它什么时候离开**
- 放完了 5 分钟没人点歌，或者语音频道里只剩它 2 分钟。
- 有人用了“停止”；被管理员踢出语音频道、或者语音一直连不上（超过 1 分钟）时，队列也会清掉。
- 在最后一次点歌的那个文字频道里，它会说一声的：自动放下一首、下载失败、放不出来跳过、语音频道没人了离开、语音断了。放完了没人点歌、安静地离开时不说。

**次数和费用**
- 写歌名点歌算一次联网搜索，和“八、联网搜索”共用每个服务器每天的次数（`每日搜索上限`，默认 30）。用完了直接贴 B站链接还能点。每个人每分钟最多按歌名点“每人每分钟点名”那么多次（默认 3 次），免得一个人一下子把全服务器的次数用光；贴链接不受这个限制。
- 找歌先用 DeepSeek 的搜索（只搜 B站，搜到了按次算钱，一次 0.075 美分）；没找到再用 Tavily（填了 `TAVILY_API_KEY` 时，每次用掉 1 次额度）；最后才用 B站自己的搜索，它很容易被 B站风控拦下来。超了每日预算时不用 DeepSeek 的搜索，Tavily 和 B站自己的搜索照常。
- 在聊天里叫它点歌，它要先点歌再回话，会多一次调用（很便宜）。
- 下载和播放都在 NAS 上，不用 B站账号：音质最高 192 kbps（更高的要大会员）。要登录、开大会员、付费才能看的视频，在你那里看不了的视频（地区限制），放不了，它会照实说原因。
- 下载的音频存在容器里的临时文件夹，放完、切掉、停止就删，重启时也会清空，不占 `data/`。

**权限**
- bot 要有那个语音频道的“连接”和“说话”权限。新的邀请链接已经带上了；之前邀请的 bot 一般也有（@everyone 默认就有这两个权限），没有的话在语音频道的设置 → 权限里给 bot 的身份组打开。
- 舞台频道放不了，要用普通的语音频道。频道满员时它进不去（除非它有“移动成员”权限）。

**出问题时**
- 它说“B站暂时把请求拦下来了（风控）”：B站觉得请求太多了，过几分钟再试。多半发生在 DeepSeek 和 Tavily 都没找到、改用 B站自己的搜索的时候；直接贴链接比较不容易被拦。队列排得很长时，后面的歌下载前可能要重新向 B站拿一次信息，这时被拦的话，它会说一声，过 3 分钟再接着下载，排着的歌不会被跳过。
- 突然所有歌都放不了（多半是 B站改版了）：要更新 yt-dlp。SSH 进 NAS，在项目文件夹里跑 `sudo docker compose build --no-cache && sudo docker compose up -d`（要加 `--no-cache` 才会装上新版的 yt-dlp）。
- 关掉点歌：`config.toml` 的 `[bot]` 里写 `music = false`，再 `docker compose up -d --force-recreate`。
- `docker compose exec dsbot python -m dsbot --check` 会显示点歌要用的东西（yt-dlp、ffmpeg、语音库）在不在；`/dsadmin 状态` 里也有一行点歌的状态。

## 十四、私信

和它同在一个服务器的人，可以直接私信它。私信里每句话都算在跟它说，不用 @。

- **私信挂在一个服务器上**：它用那个服务器的人设、长期记忆和你在那里的人设卡（设成所有服务器共用一张时就是那一张），花费也算进那个服务器的每日预算。第一次私信时自动定：只有一个共同服务器就是它；有好几个时，先挑你最近在里面跟它聊过的，并告诉你可以用 `/ds-dm 服务器` 换。换了会清空私信记录（里面是原来那个服务器的东西），服务器那边的记忆不受影响。你退出了那个服务器、或者那边关掉了私信，下次私信时它会自动换一个（同样清空私信记录）。
- **和服务器互通**：私信里聊的事，它整理记忆时可能记进那个服务器的长期记忆和你的人设卡（设成所有服务器共用一张人设卡时，写进卡的在别的服务器也会用上）。你在那个服务器的频道里叫它时，它会带上你最近在私信里跟它聊的几句（只带你自己的、最近 6 小时、最近两段），**可能在大家面前提起**；反过来，你刚在公开频道里跟它聊过的，私信里它也接得上。这两样都不用开记忆共享。别人叫它时看不到你的私信，任何频道也翻不到私信的记录。那个服务器和别的服务器连成一组时（见“七”的“服务器组”），组里的服务器都算：长期记忆、人设卡是组里共用的，在组里的服务器叫它时也会带上（`/ds-dm 状态` 会写出来）。
- **⚠️ 要保密就说一声**：私信里提到“保密”“别告诉别人”“秘密”之类的那一段，不会带到频道里，也不会记进人设卡和长期记忆（只可能记进私信记忆、标成敏感）；第一次私信、`/ds-dm 状态` 和换服务器时，它都会提醒这一点。
- **私信记忆**（2.6.0 起）：私信里聊到的、你们之间的事，比如你最近在忙什么、跟它约好的事、它答应你的事、私信里一起玩的剧情，会记进你自己的私信记忆。你的称呼、设定、喜好照旧记在人设卡里，服务器的事记在长期记忆里。
  - 怎么记：私信里叫它“记住……”当场记（会在你那条消息上加个 📝，回话里会说记成了敏感还是不敏感）；私信安静下来以后，它也会自己整理一遍。
  - **人设卡优先**：关于你自己、长期有效、又不敏感的（称呼、设定、喜好雷点、习惯、身份、爱好），先写进你在那个服务器的人设卡（所有服务器共用一张时就是那一张）；写不进人设卡的（你们之间的事、近况、约定，还有敏感的事）才记进私信记忆。
  - 每人一份，跟着你走，不分服务器，换了私信挂的服务器也还在。最多 150 条，每条 200 字；快满了它会自己合并、删掉旧的。私信里只列最近改过的那些（最多约 6000 字），在服务器里只带最近改过的 20 条不敏感的；整理记忆时它全都看得到。
  - **每条标着敏感不敏感**：健康、住址、学校单位、真实姓名、联系方式、钱、感情上的烦恼，还有你说了要保密的，都算敏感，只在私信里用。不敏感的，你在私信挂着的那个服务器（以及开了“跨服务器”的服务器）里叫它时，它也会用上，**可能在大家面前提起**。
  - 敏感不敏感是它自己判断的，可能判错，两种改法：私信里直接跟它说（“第 3 条不算敏感”“那件事别在群里说”）；或者用 `/ds-dm 记忆` 查看（只有你自己看得到），选“设为敏感 / 设为不敏感”，编号一栏输入几个字就能从你的记忆里选（记得多、列表里每条截短了，查看时选上编号能看那一条的全文）。也能删掉某条、全部清空；清空之后，它整理记忆时不会拿清空之前的聊天把它们重新记回来。
  - **敏感的事守在私信里**：就算你叫它记住，敏感的事也只记进私信记忆、标成敏感，不会写进人设卡和长期记忆（那两样服务器里的人看得到）；说到你敏感的那些事的，整理记忆时也拦下来。敏感标记只有你自己能往下调（私信里直接说，或者用 `/ds-dm 记忆`），它整理记忆、改说法时只能往上调。私信里说的那一轮要是它还看了文件、链接、搜索结果，就不会往下调（免得被里面的话骗了），这时用 `/ds-dm 记忆` 改。
  - **撤回**：某条改成敏感、你删掉或改掉某条、它把不敏感的并进了敏感的那条、清空私信记忆、私信改挂到别的服务器，或者服务器关掉了私信记忆、跨服务器，服务器频道记录里附过的会直接从记录里拿掉（和群友删消息一样），之后谁叫它都看不到了。
  - 你在频道里叫它时带上的私信近况，只带你自己说的话（它在私信里的回话不带），说到你敏感的事的那句也不带；你在私信里刚说了敏感的事（它记成了敏感），之前的私信近况都不带了。
  - 管理员、bot 主人都看不到你的私信记忆，日志和 `/dsadmin 状态` 里也不写它的想法。bot 主人用 `/dsowner 删除人设卡` 删人时会连私信记忆一起删（看不到内容）。别人的人设卡原文不会被抄进你的私信记忆。
  - 不想让这个服务器的成员有私信记忆：`/dsadmin 设置 参数:私信记忆 值:关`（只看全服务器这一级）。已经记下的还在，本人照样能看、能删。
- **等你说完再回**：连着发好几条，它等你停下 3 秒（发完又在打字就多等一会儿）再一起回，最多等 15 秒。
- **花费上限**：每个人每天私信最多花“每人每日私信预算美元”（默认 0.2 美元），到了它会说一声“今天聊得有点多了”，之后只加个 💤。那个服务器今天的预算用完了，私信也先停（留给群里的点名）。你（`OWNER_ID`）自己私信不受这两条限制，只在超过预算 2 倍时停。
- **私信里用不了的**：点歌、服务器的贴图、主动发言。服务器表情、表情包、搜索、读文件和链接照常能用，次数算那个服务器的。
- **管理员不想让成员私信**：`/dsadmin 设置 参数:私信 值:关`。之后这个服务器的成员私信它时，它会换用别的共同服务器；一个都没有就告诉他私信聊不了。

> 私信的内容也会发给 DeepSeek 处理。

## 十五、操作你的电脑（桌面小程序）

你（`OWNER_ID`）私信它时，可以让它替你开关电脑上的程序、用浏览器打开网址：“帮我开一下 Steam”“把记事本关了”“打开 https://…”。它先办，再告诉你结果。

**它能做的只有这些**：
- 开、关你在电脑上登记过的程序（白名单）。关是正常关闭，跟点右上角的叉一样，没保存的东西程序会先问你，不会强制结束。
- 用默认浏览器打开 http / https 网址，而且网址要是你自己那条消息里发的。
- 别的都不做：不跑命令、不碰文件，白名单以外的程序也开不了。

**只认你本人**：只在你自己的私信里、你这一轮亲自叫它时才办。别人私信它、在服务器频道里，都用不了。聊天记录、文件、网页、搜索结果里写的“去打开……”一律不做。

**怎么装**：
1. 生成一串随机字符当密钥：`python -c "import secrets; print(secrets.token_urlsafe(32))"`，填进 NAS 上 `.env` 的 `DESKTOP_TOKEN=`。
2. `docker-compose.yml` 里把 `ports:` 那两行前面的 `#` 去掉（让电脑能连到 bot 的 8765 端口），再 `sudo docker compose up -d --build`。日志里有 `桌面操作：等电脑上的小程序连过来` 就好了。
3. 电脑上装 Python 3.11 以上，把项目里的 `desktop_agent` 文件夹复制到电脑上，在里面运行 `pip install -r requirements.txt`。
4. 复制 `agent.example.toml` 成 `agent.toml`：`token` 填和 `DESKTOP_TOKEN` 一样的；`servers` 填 NAS 的地址（在家用局域网地址，出门用 ZeroTier 地址，两个都写，它会按顺序试）；`[apps.…]` 一段一段写上要让它开关的程序。
5. 运行 `python agent.py` 试一下：看到 `连上了 ws://…` 就好了（NAS 的日志里也会有 `电脑「…」连上了`）。
6. 想开机自动运行：按 Win+R 输入 `shell:startup`，在打开的文件夹里新建快捷方式，目标填 `pythonw "完整路径\agent.py"`（pythonw 不会弹窗口）。

**想停**：在任务管理器里结束 pythonw（窗口运行的话直接关掉窗口）；或者 `/dsowner 设置 参数:桌面操作 值:关`。电脑关机、小程序没开时，它会告诉你“电脑现在不在线”。

**安全**：电脑上的小程序是主动连 NAS 的，电脑不用开任何端口。连接用 `DESKTOP_TOKEN` 签名：连上时双方核对，之后每条指令都带签名，局域网里别人伪造不了指令，旧指令也重放不了。`DESKTOP_TOKEN` 和 Discord 账号都要保管好（建议给 Discord 账号开两步验证）：有了它们就能让它开关你电脑上登记过的程序。小程序的日志在 `desktop_agent/agent.log`。

## 十六、它是怎么工作的

```
消息进来 ──► 存进该频道的缓冲区
              │
              ├─ 是在叫它？──► 立刻跑一轮（只受每人限速）；回了话、这里又开了主动 ──► 开始“跟着”
              │
              └─ 开了主动（每 5 秒检查一次该不该跑一轮，没超预算才跑）：
                   平时：隔几分钟看一眼。最近 5 分钟有人说话 + (冷场 或 等太久) ──► 跑一轮
                         （更早攒下的消息只当背景；它开了口 ──► 开始“跟着”）
                   跟着：有人说话、停了 5 秒、离上次判断过了 30～45 秒 ──► 跑一轮
                         （5 分钟没人说话，或者连着 3 次没话说 ──► 回到平时）

一轮 = 把这批新消息编号（#12、#13…）渲染成一条 user 消息（该读的文件、该打开的链接的内容跟在后面）
      → 连同全部历史发给 DeepSeek（JSON 输出）
      → 模型返回 {"actions": [...]}：回复 / 加表情 / 发贴图 / 发表情包 / 找图 / 发找到的图 / 看文件或打开链接 /
        上网搜 / 翻别的频道 / 改人设 / 改人设卡 / 记长期记忆 / 查人设卡 / 点歌 / 什么都不做
        （要看文件、打开链接、搜索、找图、翻记录、改人设、查人设卡、点歌时：办完把结果追加进去，再问它一次）
      → 这一轮的 user + assistant 原样追加进历史（沉默也记）
      → 显示“正在输入”，按字数等几秒再发（话里的 @名字、#频道名 换成真的 @ 和频道链接）

消息被删、被编辑 ──► 缓冲区里的直接更新；已经在历史里的：删除改写那一行，编辑最近的改写那一行、早的下一轮附一句

频道安静下来（或者旧记录要压缩之前）──► 整理记忆：回顾还没整理过的聊天，更新人设卡和长期记忆

连通的频道 ──► 共用一份历史（每段写明是哪个频道的）；被叫到时先把别的连通频道还没进历史的消息补进来，只在这个频道回
```

**缓存**：历史只追加、不改写（消息被删、最近的消息被编辑时例外），system prompt 固定（时间等会变的信息放在每轮消息里），所以每次请求都以上一次的请求开头，绝大部分输入按缓存命中价计费（便宜约 50 倍）。上下文太长时把较旧的一半（按 token 估算）压成摘要，最近 6 轮不动，只在那一次 miss。日志里每轮都会打印输入 token 数和命中数。

**费用参考**（高峰价，3 万 token 上下文，缓存正常时只有新消息那几百 token 未命中）：一次判断约 0.04–0.06 美分（开思考会多一些推理 token）；一个频道全天热聊、每 3 分钟判断一次，一天约 5–10 美分。非高峰时段（含周末）半价。价格变动时改 `config.toml` 的 `[pricing]`。

## 十七、常见问题

**@ 它没反应**
- 这个频道不在允许的区域：`/dsadmin 状态` 第一行会提示，`/dsadmin 区域 查看` 看整体设置。
- 后台的 Message Content Intent 没打开（日志里会报 4014 之类的错误）。
- 频道里没给 bot 发送消息的权限。
- 你 @ 的可能是它的身份组而不是它本人——这也能识别，但如果服务器把它的身份组隐藏了就看不到。

**开了冒泡，它一直不冒**：`/dsadmin 状态` 里“冒泡”那一行会写原因：还没安静够、夜里、今天冒够了、上次冒的还没人理（等有人说话）、超了预算。冒泡只认在那个频道里开的设置；重启以后要从启动那一刻重新算安静了多久。

**主动发言一直不说话**
- `/dsadmin 状态` 看看：主动发言开了吗？“主动的节奏”那一行写的下一眼还有多久？上次判断的“想法”是什么？
- 平时它隔几分钟才看一眼（普通档 5～8 分钟），而且只接最近 5 分钟里说的话：刚说完它没反应是正常的。
- 模型默认倾向沉默。想让它更活跃：`/dsadmin 档位 档位:话痨`，或在人设里写“你很爱聊天”。

**换了人设但说话风格没变**：历史里还有旧风格的发言，`/dsadmin 清空记忆` 后重新开始。

**GIF 说看不到**：GIF 选单发的 GIF 其实是一个链接，Discord 过一两秒才补上预览图。它会读这个预览图（动图的第一帧）；如果 @ 它的那条消息自己就带链接，它会先等两秒再回。网页链接会看 Discord 生成的预览（标题、描述、预览图），被叫到时会真的打开（见“九”）。

**它说文件读不了**：看它说的原因。常见的是老格式（.doc/.xls/.ppt）、设了打开密码的文件、超过 20 MB。如果它说“解析文件的进程启动不了”，是 bot 这边的问题（日志里有详细原因，多半是权限），修好后再叫它读就行。`python -m dsbot --check`（Docker 里是 `docker compose exec dsbot python -m dsbot --check`）会检查 PDF 组件和解析子进程是否正常。

**DeepSeek 余额不足**：bot 会暂停调用 10 分钟并在日志里提示，充值后自动恢复。暂停期间有人叫它，会给那条消息加个 ⚠️。

**某批消息被 DeepSeek 拒绝**（比如触发内容审核）：如果带了图片，先去掉图片重试一次；还不行就丢掉这批消息、在日志里记一笔，不会卡住频道。连通的频道里，没问过模型就记进记录的那几条（别的频道补进来的、连通时记进它自己那份的、点歌的结果）也换成一句“没记下”；群友把最近的消息改成了被拒的内容（记录里那一行是直接改的），那几条当成删了。哪几条还没问过模型记在数据库里，中间重启了也照样认得。

**频道里发不出消息**（缺权限）：连续 3 轮发不出去，这个频道的主动发言会暂停 30 分钟，`/dsadmin 状态` 里能看到提示。

**表情显示成 :名字: / 贴图没发出来**：那个表情或贴图可能刚被删掉，或者只给某些身份组用。名单里没有的贴图它不会发，日志里会写“没有叫 XX 的贴图”。

**它说链接打不开**：要登录才能看的网站（Threads、IG、Facebook 之类）打不开；PDF 这类 DeepSeek 读不了的，填了 `TAVILY_API_KEY` 会再交给 Tavily 试。它说“读网页的服务这边出了问题”，多半是 DeepSeek 的余额不够或者 key 不对，看日志。推文打不开，可能是被删了、私密账号，或者 FxTwitter 暂时出问题。

**表情包、找到的图没发出来**：先看 bot 在那个频道有没有“附加文件”权限（日志里会有“发图失败”）。连着两轮发不出去时，那个频道 30 分钟内先不发图、也不上网找图（`/dsadmin 状态` 里会显示），补上权限后过一会儿会自己恢复。表情包名对不上库里的名字时不会发（日志里有“表情包库里没有…”）。网上找的候选图它都觉得不合适时，会选择不发。

**dsowner 让它改人设，它说改不了**：要你本人叫它（@、回复它或者叫别名），光在聊天里提一句不算；`.env` 里的 `OWNER_ID` 要是你自己的用户 ID。如果它说这个频道单独设了人设，那是你说了“全服务器”：在这个频道里不说“全服务器”就是改这里的，要改全服务器的就用 `/dsadmin 人设`。

**它没记住我说的事**：想让它马上记住，就叫它说“记住……”，记下了会加个 📝。没明确叫它记的，要等频道安静一阵它整理的时候才会记（私密频道不会自动整理）。用 `/ds-rp` 能看到自己的卡上现在写了什么，`/dsadmin 长期记忆 查看` 能看到长期记忆。

**人设卡被改坏了**：本人用 `/ds-rp 操作:改回上一版`，或者直接打开编辑框改。

**它 @ 了人，对方却没收到提醒**：只有有人叫它的时候才真的提醒，同一个人 5 分钟内只提醒一次，一次回话最多提醒 3 个人，整个服务器 10 分钟内最多 10 次（见“十二”）。它 @ 的名字对不上人（最近没说过话、没有人设卡、按名字也找不到）、名字后面没隔开、或者有两个人同名时，会保持普通文字。

**点歌说“点歌没有启用”**：`/dsadmin 状态` 里会写原因。多半是只换了 `dsbot` 文件夹，没换 `Dockerfile` 和 `requirements.txt`，镜像里没装 ffmpeg、yt-dlp 和语音库：把这两个文件也换成新的，再 `sudo docker compose up -d --build`。

**看不到 `/dsadmin`、`/ds-music`（或者别的新命令）**：
- Discord 会缓存命令列表：电脑版按 Ctrl+R（Mac 是 ⌘R）刷新，手机版把 App 完全关掉再打开。
- 管理员的命令 2.9.0 起叫 `/dsadmin`（以前叫 `/ds`，更新后旧名字就没有了，新旧写法的对照见“四、命令”）。
- 看日志里启动时那一行：会写成 `已注册 4 个全局斜杠命令：/dsadmin、/ds-rp、/ds-music、/ds-dm`，顺序可能不一样。列出来的还是 `/ds`、或者少了几个，说明跑的还是旧代码（回到“更新到新版本”那几步）；有“注册全局斜杠命令失败”，看后面写的原因。
- `config.toml` 里的 `sync_commands_on_start` 要是 `true`（默认就是）。
- 服务器设置 → 整合 → 这个 bot：管理员可能限制了谁能用它的命令。

**它说自己不能删歌、没有指令**：2.2.1 之前它确实不会删歌，也不知道有 `/ds-music`，更新以后就会了。它要是还照着自己以前在频道里说过的话回答，跟它说一句“现在可以删歌了”就行；实在不行再用 `/dsadmin 清空记忆`（会清掉这个频道的聊天记录）。

**点歌之后没声音**：看它在语音频道里头像有没有亮绿圈（在说话）。没有的话检查它在那个语音频道的“说话”权限，日志里搜“放不出来”“下载”。

**私信它没反应**：要和它同在一个服务器，而且那个服务器没关掉私信（`/dsadmin 状态` 里有一行“私信”）；今天的私信预算用完了，它会加个 💤。私信里用 `/ds-dm 状态` 看用的是哪个服务器、今天花了多少（见“十四”）。

## 十八、开发

欢迎参与改进！提 PR 之前请先看 [CONTRIBUTING.md](CONTRIBUTING.md)，里面有本地开发步骤、几条设计约束，以及中英两个版本怎么同步。每次 push 和 PR 都会由 GitHub Actions 自动跑一遍测试和离线自检。各版本的变化见 [CHANGELOG.md](CHANGELOG.md)。

```bash
python -m unittest discover -s tests      # 核心逻辑测试，不需要装 discord.py
```

读文件的测试会用 python-docx、openpyxl、python-pptx、reportlab 现场生成真实文件（只是测试用，bot 运行不需要它们；`pip install -r requirements-dev.txt` 会一起装上），没装的话对应测试会跳过。

| 文件 | 作用 |
|---|---|
| `dsbot/engine.py` | 调度引擎：缓冲、时机判断（平时隔几分钟看一眼、聊起来就跟着）、预算、执行动作、压缩摘要、跨频道记忆 |

| `dsbot/groups.py` | 服务器组：连起来（并进组里）、退出（带走一份）、组散掉；中途断了再执行一次能接着做完 |
| `dsbot/textutil.py` / `hanzi.py` | 文字整理；照念人设卡原文的检查（`hanzi.py` 是繁简对照的字表，来自 OpenCC） |
| `dsbot/mentions.py` | 把它话里的 @名字、#频道名 换成真的 @ 和频道链接 |
| `dsbot/music.py` | 点歌：找歌（DeepSeek 的搜索 / Tavily / B站搜索）、yt-dlp 下载音频、每个服务器的播放队列；Discord 语音那一层在 `discord_app.py` 的 `DiscordVoice` |
| `dsbot/llm.py` | DeepSeek HTTP 客户端（思考开关、JSON 模式、用量解析） |
| `dsbot/files.py` | 读文件：分类、解码、PDF / Office 解析、解析子进程 |
| `dsbot/dstools.py` | DeepSeek 的 Search / Fetch 接口（2026-10-17 开放，按次收费）：联网搜索、读网页、按歌名找歌都先用它 |
| `dsbot/search.py` | 联网搜索：DeepSeek 的 Search 接口，Tavily 备用 |
| `dsbot/links.py` / `tavily.py` | 读链接：推文走 FxTwitter，网页先用 DeepSeek 的 Fetch，读不了再用 Tavily Extract |

| `dsbot/commands.py` | 斜杠命令和人设编辑框 |
| `dsbot/config.py` / `settings.py` | 配置、参数定义与分层覆盖 |
| `dsbot/store.py` / `ledger.py` | SQLite 存储、每日花费 |
